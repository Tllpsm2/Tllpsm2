## ⚡ About

Backend-focused developer with a strong preference for **clean architecture** and maintainable systems. I work primarily with **ASP.NET Core** and **.NET**, expanding into the frontend ecosystem with **React**, **Angular**, and **TypeScript** — but I'll always be a backend developer at heart.

I build things because I like understanding how they work from the inside out. When I'm not writing code, I'm probably rethinking the architecture of something I already wrote.

- 🔭 Building personal projects with **ASP.NET Core** & **.NET**
- 🌱 Deepening knowledge in **TypeScript, React, Angular** & **Node.js**
- 💡 Interests: **Backend Architecture, Clean Code** & **DDD**
- 📍 Minas Gerais, Brazil
